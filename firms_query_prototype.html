FIRMS Query Builder

Builds ACE ABI Extract Reference File queries (record F111, application ID FQ) for facility, location-of-goods lookups. Source: ACE CATAIR Extract Reference File, June 25, 2018 draft, pages ERF-30 to ERF-35.

Query

Step 1: copy the EDI below and send it. The F101 input record takes no parameters and returns every region, district and port (output application ID FO). Step 2: paste the response here to pull out the district codes for the district-by-district whole-list pull.

Envelope settings

Positions follow the ACE CATAIR Batch and Block Control chapter (V20). Site, sender, processing and preparer values are all KlearNow's (2809 and S1F) and are locked. The KN number and control ID go in the user data text (positions 60-80) of the A and B records, and ACE echoes them back unchanged. The application ID is FQ for FIRMS queries, and responses come back as FO.

EDI output (updates as you type)

Every record is exactly 80 characters and sits between brackets. Remove the brackets if your sender adds its own. The ruler above the first line marks every tenth position.
